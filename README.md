# CS50's Introduction to Databases with SQL - Harvard University

Este repositório contém as minhas resoluções para os 7 *Problem Sets* e o **Projeto Final** do curso de bancos de dados da Universidade de Harvard (CS50 SQL), concluído em 2026.

## Objetivo do Repositório
Demonstrar a aplicação prática de modelagem de dados, normalização, otimização de consultas (queries), criação de *views*, *triggers* e segurança de bancos de dados relacionais.

## Tecnologias e Conceitos Aplicados
- **Linguagem:** SQL (SQLite, PostgreSQL, MySQL)
- **Modelagem:** Diagramas ER (Entidade-Relacionamento), Normalização (1NF, 2NF, 3NF).
- **Otimização:** Criação de Índices (`B-Trees`), análise de planos de execução (`EXPLAIN QUERY PLAN`).
- **Segurança:** Prevenção contra SQL Injection, controle de acessos.
